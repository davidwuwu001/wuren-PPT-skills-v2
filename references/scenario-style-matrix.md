# Scenario Style Matrix

This matrix is the control center for dynamic but consistent Wuren PPT design. Use it before generating slide code.

## Common Education Company Scenarios

### 1. Internal Partner Training

Examples: 老师赋能、顾问培训、面谈官培训、招募团队培训、城市伙伴培训。

- Audience state: needs clear method, confidence, and executable steps.
- Main structure: problem → method → demonstration → practice → action checklist.
- Best layouts: `agenda`, `sectionDivider`, `cards`, `compare`, `timeline`, `activity`, `summaryAction`.
- Font: `PingFang SC` for method pages; `Yuanti SC` for encouragement or empathy pages.
- Color: purple for structure, blue for methods/capability, orange for action points.
- Avoid: overly emotional pages without process; dense theory blocks.

### 2. Student Lesson or Workshop

Examples: 青少年成长课、爱情课工作坊、营地课程、课堂活动。

- Audience state: attention is fragile; needs simplicity, rhythm, interaction.
- Main structure: hook → question → concept → example → activity → reflection.
- Best layouts: `quote`, `activity`, `cards`, `caseStory`, `bigNumber`, `summaryAction`.
- Font: `Yuanti SC`; body 24pt+ whenever possible.
- Color: more blue/yellow/orange; keep dark purple for openings and chapter moments only.
- Avoid: management-report style charts; long bullets; small text.

### 3. Parent Talk or Education Public Class

Examples: 家长宣讲、公开课、家庭教育讲座、家长会。

- Audience state: may be anxious, skeptical, or emotionally involved.
- Main structure: empathy → common misunderstanding → child perspective → method → trust proof → next step.
- Best layouts: `quote`, `compare`, `caseStory`, `testimonial`, `bigNumber`, `summaryAction`.
- Font: `Yuanti SC` strongly preferred.
- Color: warm purple base, soft yellow/orange highlights, blue for evidence.
- Avoid: harsh red/orange warnings; sales pressure too early; dense operational details.

### 4. Camp Closing or Student Growth Report

Examples: 结营汇报、成长营总结、阶段成果展示、学员变化故事。

- Audience state: wants to see change, effort, warmth, and proof.
- Main structure: opening emotion → process review → key moments → student changes → data/proof → thanks/next stage.
- Best layouts: `cover`, `timeline`, `caseStory`, `testimonial`, `bigNumber`, `cards`, `closing`.
- Font: `Yuanti SC` for stories; `PingFang SC` for data.
- Color: purple brand base, orange/yellow celebration, blue growth proof.
- Avoid: making every page a photo album; overpacking student quotes.

### 5. Leadership Report

Examples: 项目汇报、月报、经营分析、数据复盘、问题诊断。

- Audience state: needs facts, judgment, and decisions.
- Main structure: conclusion first → key data → analysis → risks → plan → ask.
- Best layouts: `bigNumber`, `chart`, `compare`, `cards`, `timeline`, `summaryAction`.
- Font: `PingFang SC`.
- Color: dark purple headers, white content pages, blue good results, orange risks/actions.
- Avoid: cute decoration on dense pages; vague slogans; data without conclusion.

### 6. Annual or Department Summary

Examples: 年终总结、部门复盘、人事/财务/运营总结、2026规划。

- Audience state: compares achievements, gaps, and future priorities.
- Main structure: annual headline → achievements → gaps → reasons → next-year plan → resources needed.
- Best layouts: `bigNumber`, `chart`, `cards`, `compare`, `timeline`, `summaryAction`.
- Font: `PingFang SC`; use `Yuanti SC` only for team-culture pages.
- Color: purple for annual structure, blue for achievements, orange for gaps, yellow for future.
- Avoid: diary-style chronology; too many unprioritized tasks.

### 7. Proposal, Sales, or Partnership Deck

Examples: 招商方案、合作方案、课程介绍、客户提案、联营方案。

- Audience state: wants to understand value, credibility, investment, and next step.
- Main structure: opportunity → pain → solution → product/course → proof → cooperation model → call to action.
- Best layouts: `cover`, `compare`, `cards`, `caseStory`, `chart`, `summaryAction`, `closing`.
- Font: `PingFang SC` for credibility; `Yuanti SC` for parent/student benefit pages.
- Color: purple authority, blue proof/capability, orange CTA.
- Avoid: starting with company history for too long; decoration that weakens trust.

### 8. Enrollment or Recruitment Deck

Examples: 招生说明、营员招募、顾问招募、老师招募。

- Audience state: needs clarity, safety, and motivation.
- Main structure: who it is for → pain/desire → program design → outcomes → proof → process → signup/action.
- Best layouts: `quote`, `compare`, `cards`, `timeline`, `testimonial`, `summaryAction`.
- Font: `Yuanti SC` for parent/student enrollment; `PingFang SC` for internal recruitment.
- Color: warm purple, yellow hope, blue proof, orange action.
- Avoid: too many institutional claims without examples.

### 9. Public Keynote or Brand Speech

Examples: 大会演讲、品牌发布、主题演讲、对外分享。

- Audience state: needs memory points more than detail.
- Main structure: big idea → tension → three points → story/proof → final call.
- Best layouts: `cover`, `quote`, `bigNumber`, `caseStory`, `sectionDivider`, `closing`.
- Font: large `PingFang SC` or `Yuanti SC` depending on topic warmth.
- Color: stronger dark-purple hero pages and orange/yellow highlights.
- Avoid: small charts; report-style tables; too many pages with equal weight.

### 10. Knowledge Share

Examples: 读书分享、方法论分享、教研分享、技术/运营知识分享。

- Audience state: wants concepts that can be remembered and reused.
- Main structure: question → concept → framework → example → practice → takeaway.
- Best layouts: `quote`, `cards`, `compare`, `caseStory`, `timeline`, `summaryAction`.
- Font: `PingFang SC` for professional audience; `Yuanti SC` for family/student audience.
- Color: one accent color per section; avoid rainbow use.
- Avoid: copying article paragraphs directly into slides.

## Tone Selection

| Tone | Use when | Visual behavior |
|---|---|---|
| `warm` | parent, student, camp, emotional growth | More white space, rounder shapes, Yuanti SC, fewer data blocks |
| `practical` | internal training, method delivery | Clear steps, medium density, icons/checklists, blue/orange accents |
| `executive` | leadership report, annual summary | Conclusion-first, dense but aligned, PingFang SC, restrained decoration |
| `persuasive` | proposal, sales, recruitment | Benefit-led sections, proof pages, CTA contrast |
| `keynote` | public speech, brand talk | Large type, fewer words, stronger contrast, memorable rhythm |

## Layout Rhythm Guidance

Plan rhythm around the source material. These are starting points for new decks; re-theming preserves original content, order and page count by default:

- Start with `cover`.
- At a genuine topic shift or after a demanding sequence, consider a divider, question or quote already supported by the content. Do not add pages at fixed intervals or invent quotations.
- Do not place more than 3 dense slides consecutively.
- Follow a dense `chart` or `table` slide with a lower-density `summaryAction` or `quote`.
- In parent/student decks, alternate explanation slides with example/activity/reflection slides.
- In report decks, alternate result slides with analysis/action slides.


## Composition Is Not a Fixed Template

Read `design-direction-and-rhythm.md` to propose and confirm up to 3 deck-specific design directions with the user before planning. Use the scenario to choose mood and density, then choose composition from each slide’s content. Do not select a style silently when the user has not given one; continue autonomously only if the user explicitly asks you to decide. Read `ip-and-composition.md` for content-to-composition decisions. Keep brand tokens stable; do not translate every approved layout into the same card grid. For each newly authored slide, specify `layoutVariant` and a use/omit IP decision with its reason; if using IP, specify the real catalog key and placement. Always consult the catalog, but set no insertion quota; a deck without IP is valid when the scene or composition does not benefit from it. Reserve an illustration zone before sizing the text.
